What selected the moves?

SAM 3.1 identifies block pixels. Python rules combine those masks with depth, reject blocked grips, and rank candidates. Sam’s Viam routines convert coordinates and perform the movement. Codex supervised the first run and corrected the code between attempts.

The first run was not an autonomous LLM controller. Calibration, thresholds, grip style, slot spacing, and movement order were configured in code. Block positions and orientations came from new observations. Atlas similarity results did not choose the physical moves in this trial.
