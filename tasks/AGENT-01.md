# AGENT-01: Offline pick-and-place proposals from saved RGB-D

Status and owner: see board.json (single source of truth)
Role: vision (perception proposals); retrieval/storage changes coordinated with the data owner (same person today)
Plan: docs/AGENT_HEURISTICS_PLAN.md
Branch: agent-heuristics

## Goal and acceptance (first slice)

From one saved observation, produce a reviewable pick-and-place proposal or a justified abstention with no robot movement: SAM (or synthetic ground-truth) masks -> current geometry from registered depth -> finger-clearance checks adapted from Sam's `jenga.py` -> curated-reference retrieval evidence (cosine >= 0.5 over explicitly human-labelled pickable references) -> six-slot two-layer placement target -> validated proposal data (`executable: false`). Deterministic coordinator by default; OpenAI function-calling coordinator behind the cloud gate with application-side validation.

src/robot_hackathon/{retrieval,grasp_geometry,placement,synthetic_scene,proposal,coordinator,agent_report,agent_cli}.py; additive edits to config.py (OPENAI_* placeholders), cli.py (agent-* commands), rgbd_mongo.py (vector_search projection now includes curation/compatibility fields; no index change); tests/test_agent_heuristics.py; docs/SETUP.md, docs/CONTRACTS.md, .env.example.

Limitations: synthetic masks are ground truth, not SAM, so mask-quality questions (SKY-78) are untouched; no curated reference set exists yet (nothing in the local store carries an explicit `human` pickable label), so retrieval-assisted ranking is only exercised with fixtures; the Atlas adapter's filter/projection behaviour needs the authorized read-only check named in the plan; geometry constants are Sam's defaults flagged unverified; the D435 at ~680 mm standoff gives table noise comparable to block height, so Sam's plane method needs a closer camera or a different depth treatment on this setup; blocks under unverified registration read 0-2 mm tall in the live capture, consistent with RGB/depth misalignment; second-layer slots are `unvalidated_second_layer`; the OpenAI model/budget are placeholders; no scene-refresh/expiry policy (plan step 10). Nothing here establishes motion-path safety.
